## 次にやること（M1 土台）

1. `vendor/` に pdf-lib と PDF.js を置き、ライセンスファイルも一緒に置く
2. `index.html` にPWAの骨組みを作る（`manifest.webmanifest`、`sw.js` でオフライン対応）
3. モード切替（画面の幅とタッチ端末かどうかで自動判定、手動切替も）
4. PDF・画像の読み込み → ページリストに追加 → サムネイル表示
5. Coreに「ページリスト → PDF」の書き出しを作る（`src/core/` に追加し、Nodeでテストする）
6. Playwrightで画面テストを用意する（iPhone・Android・PCの画面サイズとタッチ操作を再現する）
7. Vercelで公開し、Web Analyticsを入れる（CSPは `connect-src 'self'` で足りる見込み）

完了の目安：画像1枚をPDFにして保存できる。
