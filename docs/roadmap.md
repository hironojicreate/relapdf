# 機能一覧と開発計画

## 機能一覧

### かんたんモード（スマホ・タブレット）

- 写真の取り込み：アプリ内カメラでの連続撮影／OSのカメラで撮る／ライブラリから複数選択
- 向きの自動補正（写真の回転情報と撮影時の端末の向き）
- 確認画面：並べ替え・削除・回転
- 4点補正（手動）：四隅と辺の中点をつまんで動かす、ドラッグ中のルーペ、A4比率に合わせる
- 四隅の自動検出（補正の最初の位置を賢くする）
- 書類モード：背景を白く・文字をくっきり
- 自動縮小・圧縮（標準／高画質）
- ファイル名を付けて、共有シートから保存・送信

### 詳細モード（PC）

- **第1段階**：プレビュー、結合、ページ整理（並べ替え・削除・回転）、分割・抽出、画像→PDF、PDF→画像
- **第2段階**：圧縮、ページ番号・ヘッダー/フッター、透かし・スタンプ、注釈、署名・印鑑画像、フォーム入力
- **第3段階**：割付（2in1・4in1）、用紙サイズ変換、トリミング、白紙挿入、墨消し、パスワード設定/解除、プロパティ編集、OCR

## 注意しておくリスク

- **iPhoneのメモリ**：大きな写真は読み込むときに縮小し、1枚ずつ処理する
- **自動検出ライブラリの重さ**：M5で自作の軽い処理にしたので解消（OpenCV.js は使わない）
- **日本語フォント**：使う文字だけ埋め込んでファイルサイズを抑える（M6の山場）
- **Safari特有の制約**：ファイル保存・共有・カメラまわりは、段階ごとに実機でテストする
- **Androidの実機がない**：Playwrightでの再現テストで補う。共有シートやカメラの実際の動きは実機でしか確かめられない

## 今後の課題

- **カメラのライト（トーチ）**、Android での高画質撮影（`takePhoto()`）、カメラ自体の露出の調整
- **重い処理を Web Worker に移す**（4点補正の引き伸ばし・書類モード。iPhoneで遅ければ）

- **リラメモとの連携**：今は作らない。連携するときは、同じオリジン（ドメイン）に置いて保存領域を共有するか、ファイルの受け渡しで連携するかを決める。今のうちから、Service Workerの範囲・IndexedDBのデータベース名・localStorageのキーには `relapdf` を付け、ほかのアプリとぶつからないようにしておく。
